This directory contains test cases for validating the LLVM IR Generator & Validator system.

## Directory Structure


## Test Data Files

### seeds.txt Format

```
One seed description per line
Each line is a natural language prompt for IR generation
Keep descriptions short and clear (< 100 chars recommended)

Example:
fibonacci sequence with loops
add two numbers
bubble sort algorithm
factorial using recursion
```

### expected_outputs/ Format

Golden reference IR files for regression testing.

**Naming**: `<algorithm>.ll`

**Content**: Valid LLVM IR with expected structure and semantics

**Usage**:

```python
# Compare generated IR with expected
with open("testcases/expected_outputs/fibonacci.ll") as f:
    expected = f.read()

generated = generate_llvm_ir("fibonacci")
# Both should produce same logical structure (not necessarily identical text)
```

## Regression Testing

### Adding New Regression Test

1. Generate IR for new algorithm
2. Save to `expected_outputs/<name>.ll`
3. Add seed to `seeds.txt`
4. Run batch tests
5. Verify output matches expected (exact match not required, logical equivalence OK)

### Continuous Integration

```bash
# Run on every commit
pytest tests/ -v
python -m src.batch_runner --seeds testcases/seeds.txt --output testcases/results.json
```

## Common Test Issues

### Issue: "llvm-as: command not found"

**Solution**: Install LLVM tools

```bash
sudo apt-get install llvm
```

### Issue: Timeouts on recursive tests

**Solution**: Set lower timeout or add recursion depth limit

```python
# Limit test timeout
run_ir(ir_path, timeout=5)  # 5 seconds instead of 10
```

### Issue: Different output each run

**Solution**: Use lower temperature for determinism

```python
generate_llvm_ir(seed, temperature=0.1)  # More deterministic
```

### Issue: SSA violations in loop tests

**Solution**: This is expected with high temperature. Use T=0.3

```python
generate_llvm_ir(seed, temperature=0.3)
```
